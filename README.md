# Alte Lesart

**Alte Lesart** ist ein deutsches Quellen-, Lese- und Wissensnetz für alte hebräische Texte.

Ziel: historische hebräische Primärtexte nicht nur zu sammeln, sondern benutzbar zu machen — mit deutscher Arbeitsdarstellung, Quellenkritik, Obsidian-Wikilinks, Personen-, Begriffs- und Lesepfad-Struktur.

Aktueller Schwerpunkt:

- **Führer der Unschlüssigen / מורה נבוכים** von Maimonides/Rambam
- Ibn-Tibbon-Fassung vollständig lokal als Quellenstruktur importiert
- erste Kapitel als deutsche Arbeitsfassungen ausgearbeitet

Website: <https://baum1337ine.github.io/alte-lesart/>

## Prinzipien

1. Historische Primärtexte, moderne Kommentare und editorische Hinweise werden getrennt.
2. Jede Seite erhält Quellen- und Lizenzhinweise.
3. Deutsche Arbeitsfassungen werden ehrlich als Entwurf, prüfbedürftig oder geprüft markiert.
4. Obsidian-Wissensnetz und GitHub-Pages-Ausgabe bleiben gemeinsam nutzbar.
